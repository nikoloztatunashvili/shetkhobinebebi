როგორ გამოიყენოთ ახალ ვინდოუსზე:
მხოლოდ პირველ ჯერზე:
გახსენით install.bat (სასურველია მაუსის მარჯვენა ღილაკით -> Run as administrator). სკრიპტი თავისით გადმოწერს Node.js-ს, დააყენებს ჩუმ რეჟიმში და დააინსტალირებს whatsapp-web.js, express და სხვა ბიბლიოთეკებს.
ყოველდღიური მოხმარებისთვის:
უბრალოდ ორჯერ დააკლიკეთ start.bat-ს. შავი ფანჯარა გაიშვება, ავტომატურად გახსნის ბრაუზერში http://localhost:3000-ს და აპი მზად იქნება გამოსაყენებლად.
